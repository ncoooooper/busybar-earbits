# EarBits

Train your ear on four ascending intervals with original two-note recordings and a persistent score.

Listen to the two notes, turn the wheel to choose an interval, then click to check it. Start replays the same pair. Click after feedback to hear the next question. The rear display tracks accuracy and best streak. Includes major third, perfect fourth, perfect fifth and octave.

## Run locally

From this folder, run `~/.busy-emulator/bin/busy-emulator dev --once` with BUSY Bar Emulator open. Back exits.
